## Note names

This course uses letter names. **B** is the note a half step below C (older German-style notation calls it H). **B♭** is B flat.

| Letter | C | D | E | F | G | A | B |
|---|---|---|---|---|---|---|---|
| Solfège | do | re | mi | fa | sol | la | si |

## Terms

| English | Ukrainian | Meaning |
|---|---|---|
| Interval | Інтервал | The distance between two notes |
| Semitone, half step | Півтон | One fret |
| Whole step | Тон | Two frets |
| Unison, 2nd, 3rd, 4th | Прима, секунда, терція, кварта | Interval numbers |
| 5th, 6th, 7th, octave | Квінта, секста, септима, октава | Interval numbers |
| Major, minor (interval) | Велика, мала | Interval quality |
| Perfect | Чиста | Quality of unison, 4th, 5th, octave |
| Augmented, diminished | Збільшена, зменшена | One semitone larger or smaller |
| Tritone | Тритон | Six semitones |
| Scale | Гама, звукоряд | An ordered set of notes |
| Scale degree | Ступінь | A note's position in the scale |
| Key | Тональність | A tonic plus its scale |
| Tonic | Тоніка | The home note or chord |
| Leading tone | Ввідний тон | Degree 7, a half step below the tonic |
| Key signature | Ключові знаки | The sharps or flats of a key |
| Circle of fifths | Квінтове коло | The map of all twelve keys |
| Relative keys | Паралельні тональності | Same notes, different tonic (C major and A minor) |
| Parallel keys | Однойменні тональності | Same tonic, different notes (C major and C minor) |
| Mode | Лад | A scale with its own tonic and color |
| Chord | Акорд | Three or more notes together |
| Triad | Тризвук | A three-note chord: root, 3rd, 5th |
| Root | Основний тон | The note a chord is built on |
| Inversion | Обернення | A chord with a note other than the root in the bass |
| Seventh chord | Септакорд | A triad plus a 7th |
| Power chord | Пауер-акорд, квінтакорд | Root and 5th |
| Voicing | Розташування акорду | The arrangement of a chord's notes |
| Chord progression | Акордова послідовність | A series of chords |
| Roman numerals | Римські цифри, ступені | Chords named by scale degree |
| Subdominant | Субдомінанта | The IV function |
| Dominant | Домінанта | The V function |
| Cadence | Каденція | The harmonic ending of a phrase |
| Borrowed chord | Запозичений акорд | A chord from the parallel key or mode |
| Secondary dominant | Побічна домінанта | The dominant of a chord other than the tonic |
| Modulation | Модуляція | A change of key |
| Voice leading | Голосоведення | How the notes of chords move from one to the next |
| Pedal point | Органний пункт | A held note under changing chords |
| Meter | Метр, розмір | How beats are grouped into bars |
| Bar, measure | Такт | One group of beats |
| Beat | Доля | The basic pulse |
| Subdivision | Дроблення | How a beat is split |
| Syncopation | Синкопа | An accent off the expected beat |
| Backbeat | Бекбіт, слабка доля | The snare on beats 2 and 4 |
| Riff | Риф | A short repeated instrumental idea |
| Palm muting | Глушіння долонею | Damping the strings with the picking hand |
| Motif | Мотив | A short melodic idea |
| Phrase | Фраза | A musical sentence |
| Verse, chorus | Куплет, приспів | Song sections |
| Pre-chorus, bridge | Передприспів, бридж | Song sections |

| Arrangement | Аранжування | Who plays what, and when |
| Register | Регістр | How high or low a part sits |
| Dynamics | Динаміка | Loudness and intensity |
| Prosody | Просодія | The fit between words and music |
| Drone | Бурдон | A long held note used as a tonal center |
